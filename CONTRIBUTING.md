# Contributing to the AURIORA hub

This repository is the navigation index of the AURIORA ecosystem. Contributions here concern the index itself, not the projects it points to.

## What belongs here

This repository does not take issues or pull requests. Write to [contact@auriora.org](mailto:contact@auriora.org) about:

- broken or outdated links
- missing repository entries
- incorrect project descriptions or statuses
- organization-level navigation problems
- suggestions about the ecosystem structure

## What belongs elsewhere

Technical changes — bug reports, feature requests, design questions, documentation fixes for a specific project — belong in the repository where that work lives. Find it in the [README](./README.md) index and follow that repository's contribution instructions.

## Proposing a new repository entry

Send an email naming the repository, the section it belongs to (standards and guides, hardware modules, firmware, software, research and data, websites) and a one-line description. Descriptions are factual and concise: what the repository contains, not marketing. Statuses use the [repository status legend](./README.md#repository-status-legend).

## Standards

Changes follow the [AURIORA Documentation Standard](https://github.com/auriora-org/auriora-documentation-standard): plain professional English, descriptive link text, no broken links, no entries for repositories that do not exist.
